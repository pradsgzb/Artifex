# Changelog

## 2.0.0

- Reorganized the application around domain policies, dependency-inversion protocols, application use cases, infrastructure adapters, and independent composition roots.
- Added configurable colorful console logging and strict logging levels.
- Added Windows, macOS, and Linux launchers for Prompts, Organize, Server, setup, verification, frontend build, and source packaging.
- Added adaptive JSON recovery with bounded token growth and in-memory-only image reduction.
- Added typed configuration validation and platform-specific path overrides.
- Added lossless Subject JSON merge behavior that preserves unknown fields.
- Hardened timestamp handling, collision safety, cross-filesystem moves, and large archive bucket naming.
- Made SQLite inference cache safe for concurrent API access.
- Added the embedded FastAPI service, REST contracts, authentication, request limits, upload validation, and bounded inference queue.
- Added an Angular chat client and a zero-build embedded fallback client.
- Added automated regression coverage for core, API, filesystem, caching, configuration, and launcher behavior.
